# ADR-002: .NET 10

- Estado: Aceptada
- Fecha: 2026-10-15

## Contexto

El proyecto necesita una versión de .NET con soporte a largo plazo durante todo su desarrollo y más allá del MVP. El SDK instalado es el 10.0.300 y se fija con `global.json`.

## Decisión

Se usa .NET 10 (`net10.0`), versión LTS con soporte hasta noviembre de 2028.

## Consecuencias

### A favor

- Soporte y parches de seguridad durante varios años.
- Versión actual de EF Core, ASP.NET Core y el SDK.

### En contra

- Algunos paquetes de terceros pueden no tener aún soporte para .NET 10. Si ocurre, se anota en el ADR correspondiente y se busca una alternativa antes de forzar versiones antiguas.

## Alternativas descartadas

- **.NET 8 y .NET 9:** su soporte termina el 10 de noviembre de 2026, es decir, en semanas. Empezar un proyecto nuevo sobre ellos obligaría a migrar casi de inmediato.
